## How this roadmap is generated

- **Source of truth:** GitHub milestones and labels. The roadmap is a derived,
  regenerated artifact and is never hand-edited independently.
- **Bucketing:**
  - **Now** — open issues in the milestone currently marked active.
  - **Next** — open issues in the next planned milestone.
  - **Later** — open issues in milestones planned beyond that.
- **Excluded:** issues without a milestone are intentionally omitted rather than
  mis-bucketed into an arbitrary column.
- **Staleness:** the `Last synced` timestamp above is refreshed on every run so
  the freshness of this view is never ambiguous.
