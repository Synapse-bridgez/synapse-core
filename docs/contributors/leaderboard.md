This leaderboard tracks cumulative contributor achievements across Wave issues:
points earned, categories contributed to, and active streaks. It is derived
purely from merged PR metadata (the linked issue and its complexity/point label).

## How points are attributed

1. When a PR is merged, the workflow reads the PR body and title for closing
   keywords (`Closes #123`, `Fixes #123`, `Resolves #123`).
2. For each linked issue, the issue's complexity label is resolved to a point
   value using the table below.
3. Points are credited to the PR author. A PR that closes multiple issues
   credits the sum of all resolved issues.
4. If any linked issue has a missing or ambiguous complexity label, the PR is
   **flagged for manual review** and no points are attributed until a maintainer
   resolves the label. Flagged PRs are listed in the *Needs review* section.

## Categories

Categories are derived from the labels on the linked issues (for example
`governance`, `community`, `docs`, `tooling`). A contributor's category list is
the union of categories across all of their merged Wave PRs.
